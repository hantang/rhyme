# 诗歌韵部

## 缘起

网络公开可查询的诗歌韵部，往往来自早年电子资料的转载或加工，往往错讹难辨，或者字数偏少。
今参考几种出版物（或影印本）的原始资料，结合ORC、人工校对、网络资料等重新汇整，保持原汁原味，以供参考，欢迎方家指正。

## 说明

本仓库韵字表参考出版物的扫描电子版整理，尽量保持原始结构和用字字形，不作校勘，其中：
- 文件使用`UTF-8`编码；
- 使用markdown风格标题（`#`开头）标记主标题和子标题等，区分正文字表，原文标题分行合并为一行；
- 使用分隔线`---` 表示分页，但一般不再记录页面页码；
	- `***` 用于分隔正文字表和说明文字（前言等）。
- 使用引用`>`表示注释，如无特殊说明，注释均来自本仓库整理者，和原始资料无关，主要用于表示存在差异的新旧字形、异体字，校对说明等；
- 使用html风格注释`<!-- -->`在正文区分卷、作者等来自原文但非字表相关信息；
- 正文前附加前辅文（frontmatter），使用`---`包围，说明基本信息；
- 正文分行和原文尽量保持一致，原文正文内加行注释以`()`表示，其他符号一般与原始资料同；
	- 刻本字表网格状排序时，以制表符`\t`分割正文字，双行注释仍保持完整，不受换行或分页影响。
- 文字尽可能选择字形一致的编码；差异明显或者缺少编码的字选择相近的异体字代替，并适当注释说明及IDS；
	- 新旧字形（如“𥁕昷”、“录彔”、“吴吳”、“兑兌”、“真眞”等）存在独立的编码的使用对应编码。
- 对明显错讹（如重复、错印等）的作少量校对，但一般不在正文中订正，仅注释说明；受限于资料和水平仅供参考。
	- 对重复文字进行说明，对可修正的，重复字后加`※`以标识区分。
- `configs`目录中“形近字”大部分为异体字（但可能不完全等同），少量为字形相近但非异体字，主要用于比较不同版本收字差异。

## 韵部简释

### 诗韵

诗韵的出现和近体诗（格律诗）的成型密切相关，音韵以“今音”（即中古音系，南北朝—隋唐）为基准，隋代《切韵》（193韵）、唐代《唐韵》（195年）、北宋《广韵》《集韵》《礼部韵略》（均206韵）等一脉相承。

常用诗韵为“平水韵”，源自南宋—金代编撰的《礼部韵略》（南宋刘渊《壬子新刊礼部韵略》〔107韵〕、金代王文郁《平水新刊礼部韵略》〔106韵〕），均基于《广韵》等合并简化，此后诗韵分部基本保持稳定。

目前以清代康熙年间官方成书106韵的《佩文韵府》最为完善，便于科举应试和考评，不过文字排列方式从同音分组改成按常用难易程度排序，之后有《韵府拾遗》补充。
其后若干简化、增补的本子流行，如《佩文诗韵释要》《诗韵合壁》《增广诗韵集成》等。

### 词韵

词韵通常是诗韵的合并简化，但长期没有通行的成书流行。从明代开始词脱离音乐，成为完全文字性工具后，才有词律、词谱、词韵的研究和整理。
目前以清代学者戈载私编的《词林正韵》最为流行，承袭沈谦、仲恒一派划分为19韵部，只是此书韵目以《集韵》为准。
另外也有其他词韵方案，通常基于诗韵106韵简化合并。

### 曲韵

曲韵（北曲）以入声消失后的近代音为基础，元代周德清所编《中原音韵》最为知名，共分为19韵部，同时“平分阴阳，入派三声”。
另有卓从之的《中州乐府音韵类编》，思路相近。这个分部编排形成之后戏曲领域常用的十三辙。

南戏（南曲）早期没有专门韵书，在明代洪武年间官修的《洪武正韵》未能成功取得《礼部韵略》（即传统“平水韵”方案）后，反而成为南戏的曲韵参考。
明代朱权《琼林雅韵》、王文璧《中州音韵》同样分19部，适用南戏，最大特点是平声不分阴阳。其后清代以来南戏曲韵则微调为通用21部。

### 新韵

新韵泛指区别于传统“平水韵”的分韵方案，核心是以普通话（国语）为基础划分韵部。常见的韵母划分从9到24部等不一，基本是“十三辙”的扩缩。
由于方案制作者学识和水平不一，同时和创作环境、理念等有明显脱离，因此迄今没有流行和达成共识的方案。

以《汉语新诗韵论》中“各新诗韵书间存在的歧义现象”等为主，参考其他资料等总结常见的新韵方案，以汉语拼音划分韵部，不列举韵字。
